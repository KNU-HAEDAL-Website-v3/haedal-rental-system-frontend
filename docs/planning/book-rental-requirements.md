# Requirement Type

- Club Book Rental System (동아리 도서 대여 관리 시스템)

---

# Requirements

| 요구사항 순번 | 내용 |
| :---: | :--- |
| 1 | 이 기능을 사용하려면 이용자가 시스템에 로그인되어 있어야 하며, 운영진의 가입 승인을 받은 활동회원이어야 한다. <br>또한 대여 대상 도서가 시스템에 등록되어 있고 해당 도서의 실물에 식별용 라벨이 부착되어 있어야 하며, 이용자의 기기에서 라벨을 인식할 수 있어야 한다. |
| 2 | 이용자가 도서를 검색하면 시스템은 제목, 저자, 분류를 기준으로 등록된 도서를 찾아 목록으로 보여주어야 한다. <br>시스템은 각 도서의 대여 가능 여부를 함께 표시해야 하며, 이미 대여된 도서에 대해서는 반납 예정일을 표시해야 한다. 이용자는 동아리방에 방문하지 않고도 이 정보를 확인할 수 있어야 한다. |
| 3 | 이용자가 대여를 요청하면 시스템은 이용자가 제시한 라벨을 읽어 어떤 도서의 어떤 실물인지 식별해야 한다. <br>시스템은 식별한 도서의 제목과 저자를 이용자에게 보여주고 이용자의 확정 입력을 받은 뒤에 대여를 처리해야 한다. 같은 책이 여러 권 있는 경우 시스템은 각 실물을 서로 다른 것으로 구분해야 한다. |
| 4 | 시스템은 대여를 확정하기 전에 이용자가 도서를 빌릴 수 있는 상태인지 확인해야 한다. <br>확인 항목은 해당 실물이 이미 다른 사람에게 대여 중인지 여부, 이용자에게 반납 기한이 지난 도서가 있는지 여부, 이용자가 동시에 빌릴 수 있는 권수를 넘었는지 여부이다. 어느 하나라도 충족하지 못하면 대여를 진행하지 않아야 한다. |
| 5 | 확인을 모두 통과하면 시스템은 대여를 확정하고 대여자, 대여 도서, 대여 일자를 자동으로 기록해야 한다. <br>이때 시스템은 대여 일자를 기준으로 반납 예정일을 자동으로 계산하여 부여해야 하며, 해당 실물의 상태를 대여 중으로 변경하고 이용자에게 반납 예정일을 안내해야 한다. 이용자가 직접 대여 일자나 자신의 이름을 적는 절차는 없어야 한다. |
| 6 | 이용자가 도서를 반납하면 시스템은 라벨을 읽어 해당 대여 건을 찾고 반납 일자를 자동으로 기록해야 한다. <br>시스템은 해당 실물의 상태를 다시 대여 가능으로 변경하고, 반납이 완료되었다는 사실과 도서를 꽂아야 할 보관 위치를 이용자에게 표시해야 한다. 반납이 늦은 경우에는 연체 일수를 함께 알려야 한다. |
| 7 | 이용자가 반납 예정일까지 도서를 다 읽지 못한 경우 시스템은 반납 예정일을 미룰 수 있게 해야 한다. <br>다만 연장은 정해진 횟수까지만 허용해야 하며, 이미 반납 기한이 지난 도서이거나 허용 횟수를 모두 사용한 도서는 연장할 수 없다는 사실과 그 사유를 이용자에게 알려야 한다. |
| 8 | 시스템은 이용자가 반납 기한을 잊지 않도록 반납 예정일이 가까워지면 미리 알려야 한다. <br>반납 기한이 지난 경우에는 연체 사실을 이용자에게 반복하여 알려야 하며, 운영진은 현재 연체 중인 도서와 대여자를 한 화면에서 확인할 수 있어야 한다. |
| 9 | 라벨이 훼손되었거나 기기가 라벨을 읽지 못하면 시스템은 대여나 반납을 중단하지 않고 다른 방법을 제공해야 한다. <br>이 경우 이용자는 제목이나 저자로 도서를 검색하여 직접 선택할 수 있어야 하며, 같은 책이 여러 권일 때는 어떤 실물을 빌리는지 구분하여 선택할 수 있어야 한다. |
| 10 | 이용자가 도서를 빌릴 수 없는 상태이면 시스템은 대여를 처리하지 않고 그 사유를 구체적으로 알려야 한다. <br>해당 실물이 이미 대여 중이면 반납 예정일을 함께 알려야 하고, 이용자에게 연체 도서가 있으면 어떤 도서를 먼저 반납해야 하는지 알려야 하며, 대여 권수를 넘었으면 현재 빌린 권수와 허용 권수를 함께 알려야 한다. |
| 11 | 로그인하지 않은 사람이나 아직 운영진의 승인을 받지 못한 사람이 대여를 시도하면 시스템은 요청을 처리하지 않아야 한다. <br>이 경우 시스템은 대여를 하려면 어떤 절차가 필요한지 안내해야 하며, 승인 전이라도 도서 목록과 대여 가능 여부는 확인할 수 있게 해야 한다. |
| 12 | 이용자가 도서를 잃어버렸거나 도서가 훼손된 경우 운영진은 해당 실물의 상태를 분실 또는 파손으로 변경할 수 있어야 한다. <br>또한 이용자가 시스템을 거치지 않고 도서를 책꽂이에 꽂아 두었거나 대여자가 직접 반납 처리를 하지 못하는 상황에서는 운영진이 대신 반납을 처리할 수 있어야 하며, 이때 처리 사유를 남겨야 한다. |
| 13 | 시스템에 등록되지 않은 도서나 라벨이 붙어 있지 않은 도서를 이용자가 대여하려 하면 시스템은 해당 도서를 대여할 수 없음을 알려야 한다. <br>이 경우 이용자는 운영진에게 도서 등록을 요청할 수 있어야 하고, 운영진은 도서를 등록하고 라벨을 발급하여 대여가 가능한 상태로 만들 수 있어야 한다. |
| 14 | 시스템에 접속할 수 없거나 처리 중 오류가 발생하면 시스템은 대여나 반납이 완료된 것처럼 표시하지 않아야 한다. <br>이 경우 시스템은 처리에 실패했다는 사실과 사유를 이용자에게 알려야 하며, 이용자가 다시 시도하거나 운영진에게 알릴 수 있도록 안내해야 한다. 같은 도서를 두 번 스캔하더라도 대여 기록이 중복으로 생기지 않아야 한다. |
| 15 | 시스템은 지금까지의 대여와 반납 내역을 모두 보관해야 한다. <br>이용자는 자신이 빌렸던 도서의 내역을 확인할 수 있어야 하고, 운영진은 도서별 대여 내역과 전체 대여 현황을 확인할 수 있어야 한다. 도서를 폐기하거나 이용자가 동아리를 떠나더라도 지난 내역이 사라지지 않아야 한다. |
| 16 | 정상적으로 완료된 경우에는 해당 실물이 대여 중 또는 대여 가능 상태로 바뀌어 있어야 하며, 시스템에 대여자, 대여 일자, 반납 예정일, 반납 일자가 기록되어 있어야 한다. <br>요청을 완료하지 못한 경우에는 대여나 반납이 기록되지 않은 상태가 유지되어야 하며, 도서의 상태도 요청 전과 동일하게 남아 있어야 한다. 실패한 요청의 사유는 이용자가 확인할 수 있어야 한다. |

# List of Senarios

| Senario Title | Kind | Description |
| :--- | :--- | :--- |
| 정상적인 도서 대여 | Basic | 활동회원이 도서를 검색하여 대여 가능 여부를 확인하고, 동아리방에서 도서의 라벨을 읽히면, 시스템이 도서를 식별하고 대여 자격을 확인한 후 대여를 확정하고 반납 예정일을 부여하여 안내한다. |
| 정상적인 도서 반납 | Basic | 활동회원이 반납할 도서의 라벨을 읽히면, 시스템이 해당 대여 건을 찾아 반납 일자를 기록하고, 도서를 다시 대여 가능 상태로 변경한 후 보관 위치와 함께 반납 완료를 표시한다. |
| 방문 전 재고 확인 | Optional | 이용자가 동아리방에 방문하기 전에 도서를 검색하면, 시스템이 해당 도서의 대여 가능 여부를 표시하고, 이미 대여 중이면 반납 예정일을 함께 보여준다. |
| 라벨 인식 실패 | Optional | 라벨이 훼손되어 기기가 인식하지 못하면, 시스템은 제목이나 저자로 검색하여 도서를 직접 선택하는 방법을 제공하고, 선택한 도서로 대여를 계속 진행한다. |
| 이미 대여 중인 도서 | Optional | 이용자가 다른 사람이 빌려간 도서를 대여하려 하면, 시스템은 대여를 처리하지 않고 해당 도서가 대여 중이라는 사실과 반납 예정일을 표시한다. |
| 연체 회원의 대여 시도 | Optional | 반납 기한이 지난 도서를 가진 이용자가 새로 대여하려 하면, 시스템은 대여를 처리하지 않고 먼저 반납해야 할 도서를 알린다. |
| 대여 권수 초과 | Optional | 이용자가 동시에 빌릴 수 있는 권수를 모두 사용한 상태에서 대여하려 하면, 시스템은 대여를 처리하지 않고 현재 빌린 권수와 허용 권수를 표시한다. |
| 미승인 회원의 대여 시도 | Optional | 아직 운영진의 승인을 받지 못한 사람이 대여하려 하면, 시스템은 요청을 처리하지 않고 승인 절차를 안내하되 도서 목록 조회는 계속 허용한다. |
| 대여 기간 연장 | Optional | 이용자가 반납 예정일 전에 연장을 요청하면, 시스템은 허용 횟수 이내인지 확인한 후 반납 예정일을 미루고 변경된 날짜를 안내한다. |
| 연장 불가 | Optional | 이미 반납 기한이 지났거나 연장 횟수를 모두 사용한 도서에 대해 연장을 요청하면, 시스템은 연장을 처리하지 않고 그 사유를 알린다. |
| 연체 상태의 반납 | Optional | 반납 기한이 지난 도서를 반납하면, 시스템은 반납을 정상 처리하되 연체 일수를 함께 표시하고, 해당 이용자의 대여 제한을 해제한다. |
| 반납 예정일 사전 알림 | Optional | 반납 예정일이 가까워지면, 시스템이 대여자에게 반납이 임박했다는 사실과 대상 도서를 알린다. |
| 연체 발생 알림 | Optional | 반납 기한이 지나면, 시스템이 대여자에게 연체 사실을 반복하여 알리고, 운영진에게는 연체 중인 도서와 대여자 목록을 제공한다. |
| 미등록 도서 대여 시도 | Optional | 시스템에 등록되지 않았거나 라벨이 없는 도서를 대여하려 하면, 시스템은 대여할 수 없음을 알리고 운영진에게 등록을 요청하는 방법을 안내한다. |
| 운영진의 대리 반납 | Optional | 이용자가 시스템을 거치지 않고 도서를 꽂아 두면, 운영진이 해당 대여 건을 찾아 대신 반납 처리하고 처리 사유를 남긴다. |
| 도서 분실·파손 처리 | Optional | 대여한 도서를 잃어버렸거나 훼손된 상태로 반납하면, 운영진이 해당 실물의 상태를 분실 또는 파손으로 변경하여 더 이상 대여되지 않게 한다. |
| 중복 스캔 | Optional | 이용자가 같은 도서의 라벨을 연속으로 여러 번 읽히더라도, 시스템은 대여 기록을 하나만 생성하고 이미 처리된 요청임을 알린다. |
| 처리 중 오류 발생 | Optional | 대여나 반납을 처리하는 도중 접속이 끊기거나 오류가 발생하면, 시스템은 완료로 표시하지 않고 실패 사유를 알리며 도서 상태를 요청 전과 동일하게 유지한다. |
| 대여 내역 조회 | Optional | 이용자가 자신의 대여 내역을 조회하면 지난 대여와 반납 기록을 보여주고, 운영진이 조회하면 도서별 대여 내역과 전체 대여 현황을 보여준다. |
