# 에이전트 작업 지침

이 문서는 AI 에이전트의 공통 작업 지침입니다. `CLAUDE.md`와 `GEMINI.md`가 이 파일을 함께 불러옵니다. 지침을 바꿀 때는 이 파일만 수정합니다.

---

# 1. 프로젝트 개요

## 가. 무엇을 만드는가

동아리방의 종이 대여 장부를 웹 시스템으로 대체합니다. 회원이 라벨을 스캔해 도서를 대여하고 반납합니다. 향후 동아리 전체 물품 관리로 확장합니다.

## 나. 현재 단계

| 구분 | 내용 |
| --- | --- |
| 진행 상태 | 기획 완료, 개발 착수 준비 |
| 직전 목표 | 2026-08-31 프로토타입 구현과 시범 운영 |
| 프로토타입 범위 | 요구사항 41건 중 19건 |
| 진행 방식 | 디자인·프론트엔드·백엔드 병렬 |

상세 일정과 범위는 `docs/planning/project-definition.md`를 따릅니다.

## 다. 확정된 정책

1) 인증: Google 계정 로그인 후 운영진 승인  
2) 도서 식별: QR 라벨 스캔, 실패 시 제목·저자 검색  
3) 대여: 셀프 대여, 반납예정일 자동 부여  
4) 데이터: 회원 정보와 이력은 동아리방 데스크탑에서 자체 관리

# 3. 문서 규칙

## 가. 작성 형식

모든 문서는 `docs/creating-rules/`의 규칙을 따릅니다. `CLAUDE.md`와 `GEMINI.md` 상단에서 불러옵니다.

1) 항목 기호: 대항목 `1.` → 중항목 `가.` → 소항목 `1)` → 세소항목 `가)`  
2) 표: `| 구분 | ... | 비고 |` 형식  
3) 서술: 구체적 내용은 서술식, 세부 요소는 개조식  
4) 문체: 평서형(`~한다`)으로 통일

# 5. 행동 지침

LLM의 흔한 실수를 줄이기 위한 지침입니다. 사소한 작업에는 판단에 따라 적용합니다.

## 가. 코딩 전에 생각한다

**단정하지 않는다. 혼란을 감추지 않는다. 절충점을 드러낸다.**

구현 전에 확인합니다.

1) 가정을 명시합니다. 불확실하면 묻습니다.  
2) 해석이 여러 갈래면 모두 제시합니다. 조용히 하나를 고르지 않습니다.  
3) 더 단순한 방법이 있으면 말합니다. 필요하면 반대 의견을 냅니다.  
4) 불분명하면 멈춥니다. 무엇이 혼란스러운지 이름 붙이고 묻습니다.  

## 나. 단순함이 먼저다

**문제를 푸는 최소한의 코드만 씁니다. 추측으로 만들지 않습니다.**

1) 요청하지 않은 기능은 넣지 않습니다.  
2) 한 번만 쓰는 코드에 추상화를 만들지 않습니다.  
3) 요청하지 않은 유연성이나 설정 가능성을 넣지 않습니다.  
4) 일어날 수 없는 상황에 예외 처리를 넣지 않습니다.  
5) 200줄을 썼는데 50줄로 가능하면 다시 씁니다.  

기준: "숙련된 개발자가 과하다고 말할까?" 그렇다면 단순화합니다.

## 다. 최소 범위만 수정한다

**꼭 필요한 곳만 건드립니다. 자기가 만든 흔적만 정리합니다.**

기존 코드를 수정할 때 지킵니다.

1) 인접한 코드, 주석, 서식을 개선하지 않습니다.  
2) 고장나지 않은 것을 리팩터링하지 않습니다.  
3) 다르게 하고 싶더라도 기존 스타일에 맞춥니다.  
4) 관련 없는 죽은 코드를 발견하면 알리되 삭제하지 않습니다.  

변경으로 고아가 생긴 경우 지킵니다.

1) 내 변경 때문에 쓰이지 않게 된 import·변수·함수는 제거합니다.  
2) 원래 있던 죽은 코드는 요청 없이 제거하지 않습니다.  

기준: 변경한 모든 줄이 요청과 직접 연결되어야 합니다.

## 라. 목표를 정하고 검증한다

**성공 기준을 정합니다. 검증될 때까지 반복합니다.**

작업을 검증 가능한 목표로 바꿉니다.

1) "검증 추가" → "잘못된 입력에 대한 테스트를 쓰고 통과시킨다"  
2) "버그 수정" → "재현 테스트를 쓰고 통과시킨다"  
3) "리팩터링" → "전후로 테스트가 통과하는지 확인한다"  

여러 단계로 이루어진 작업은 계획을 먼저 밝힙니다.

```
1. [단계] → 검증: [확인 방법]
2. [단계] → 검증: [확인 방법]
3. [단계] → 검증: [확인 방법]
```

성공 기준이 명확하면 스스로 반복할 수 있습니다. 기준이 약하면 계속 되물어야 합니다.
